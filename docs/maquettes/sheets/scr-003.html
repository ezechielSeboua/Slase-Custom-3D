Notes

  1. Scène : rotation libre (glisser), zoom (molette, pincer). Vues rapides FACE / DOS / 3/4 animées, instantanées avec « mouvement réduit ».
  2. L’étiquette d’aperçu indicatif reste visible dans tous les états, y compris pendant l’export.
  3. Annuler / rétablir : boutons ↶ ↷ et Ctrl+Z / Ctrl+Y. Désactivés quand l’historique est vide.
  4. Les panneaux défilent indépendamment de la scène.
  5. Sur mobile, les réglages du vêtement passent dans l’onglet « Vêtement » du panneau bas.
  6. Détail A : voir UI-HDL-001 (zone de toucher 44 autour de la poignée de 12).
  7. Le nom de la création est un champ éditable ; il est tronqué avec « … » s’il dépasse.
